# AEGIS in the Classroom — educator one-pager

## What it is
A free, local-first OSINT investigation lab: 20 tools behind one
window, a dossier builder that teaches *method* (findings → methods
→ gaps → caveats), and zero-key starting paths so class begins in
minute one, not after API paperwork.

## Why it's classroom-safe
- **No accounts, no keys, no cloud.** Nothing leaves the machine.
  Keys tab stays empty; every core exercise runs keyless.
- **Role-gated logins.** Instructor is admin; students get only the
  passive tools (dorks, archives, username/email checks). Active
  probing modules (nmap, deauth) are simply never granted — the
  buttons render dimmed with "see admin."
- **Attribution discipline built in.** Reports state methods, demand
  second discriminators, and log gaps instead of hiding them.
  The tool teaches "a hit is not an attribution" by structure.
- **Licensed MIT.** Install on every lab machine, no seats, no fees.

## A 30-minute first lab (zero prep)
1. Install (one command, ~10 min unattended downloading).
2. Dorks tab: pick an engine, scope `example.com`, open 3 dorks.
   Discuss: indexed ≠ live — verify everything. (10 min)
3. Dossier tab: build a case on `example.com` with Sherlock
   skipped, read the REPORT together: findings vs gaps. (10 min)

## What students learn
Passive vs active recon (and why authorization matters), source
triangulation, report writing with caveats, API-key hygiene via
the vault model — without ever touching a live target.
